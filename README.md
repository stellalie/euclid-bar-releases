# euclid-bar

A blazing fast, developer-first search bar for macOS: apps, files, clipboard, browser history and
any CLI as an action.

## Download

**[Download the latest version](https://github.com/stellalie/euclid-bar-releases/releases/latest)**
(`euclid-bar-<version>.dmg`, macOS 14+, Apple Silicon + Intel).

1. Open the DMG and drag **euclid-bar** into **Applications**.
2. Launch it and press **⌥Space**.

Builds are signed with a Developer ID and notarized by Apple. The app updates itself (menu bar ›
*Check for Updates…*).

---

This repository only hosts releases and the update feed. The source code is private.
