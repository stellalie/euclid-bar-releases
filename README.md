# euclid-bar

A blazing fast, developer-first search bar for macOS: apps, files, clipboard, browser history and
any CLI as an action.

## Download

With [Homebrew](https://brew.sh):

```sh
brew tap stellalie/euclid https://github.com/stellalie/euclid-bar-releases
brew install --cask stellalie/euclid/euclid
```

Or **[download the latest version](https://github.com/stellalie/euclid-bar-releases/releases/latest)**
(`Euclid-<version>.dmg`, macOS 14+, Apple Silicon + Intel).

1. Open the DMG and drag **Euclid** into **Applications**.
2. Launch it and press **⌥Space**.

Builds are signed with a Developer ID and notarized by Apple. The app updates itself (menu bar ›
*Check for Updates…*).

---

This repository only hosts releases, the update feed and the Homebrew cask (`Casks/`). The source code is private.
The website lives at [lgtm.ninja/euclid](https://lgtm.ninja/euclid/) (source: stellalie/lgtmworks, `euclid/`).
