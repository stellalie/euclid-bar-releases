Recipes

Paste any of these into ~/.config/euclid/config.toml. It reloads on save. Your query arrives as $1 ($EUCLID_QUERY_URL is URL-encoded); type an alias plus a space to run one directly.

Ask Claude in a new Ghostty tab

AI agents

Type a question, ⌘↵, and Claude Code opens in a fresh tab with it.

[[action]]
name = "Ask Claude in a new Ghostty tab"
run  = 'ghostty-run tab claude "$1"'

Codex in a herdr split

AI agents

Keep your current pane; Codex answers next to it.

[[action]]
name = "Codex in a herdr split"
run  = 'herdr-run split codex "$1"'

Ask pi in a new Ghostty window

AI agents

A separate window for longer sessions.

[[action]]
name = "Ask pi in a new window"
run  = 'ghostty-run window pi "$1"'

Search GitHub code

Code

Type gh, a space, and what you are looking for.

[[action]]
name  = "Search GitHub code"
alias = "gh"
run   = 'open "https://github.com/search?type=code&q=$EUCLID_QUERY_URL"'

Open a GitHub repo

Code

Type owner/repo and land on it.

[[action]]
name = "Open repo"
run  = 'open "https://github.com/$1"'

Open a project in VS Code

Code

Any path or repo name under ~/code.

[[action]]
name = "Open in VS Code"
run  = 'code "$HOME/code/$1"'

npm package

Packages

Jump straight to a package page.

[[action]]
name  = "npm package"
alias = "npm"
run   = 'open "https://www.npmjs.com/package/$1"'

Rust crate

Packages

docs.rs for any crate.

[[action]]
name  = "Rust crate docs"
alias = "rs"
run   = 'open "https://docs.rs/$1"'

Go package

Packages

pkg.go.dev search.

[[action]]
name  = "Go package"
alias = "go"
run   = 'open "https://pkg.go.dev/search?q=$EUCLID_QUERY_URL"'

Open a Jira issue

Atlassian

Type jira ABC-123. Set your site once in [env].

[env]
JIRA = "https://your-site.atlassian.net"

[[action]]
name  = "Open Jira issue"
alias = "jira"
run   = 'open "$JIRA/browse/$1"'

Search Confluence

Atlassian

Find the page you half remember. Uses JIRA from the recipe above.

[[action]]
name  = "Search Confluence"
alias = "wiki"
run   = 'open "$JIRA/wiki/search?text=$EUCLID_QUERY_URL"'

Terminal

Free a port

Terminal

Type port 3000 to kill whatever is listening on it.

[[action]]
name  = "Kill process on port"
alias = "port"
run   = 'lsof -ti tcp:"$1" | xargs kill'

Pretty-print JSON to clipboard

Utilities

Paste minified JSON, get it formatted (needs jq).

[[action]]
name = "Pretty JSON to clipboard"
run  = 'printf %s "$1" | jq . | pbcopy'

Random password to clipboard

Utilities

24 random bytes, base64, no newline.

[[action]]
name  = "New password"
alias = "pw"
run   = 'openssl rand -base64 24 | tr -d "\n" | pbcopy'

Explain a shell command

Utilities

[[action]]
name  = "Explain shell command"
alias = "explain"
run   = 'open "https://explainshell.com/explain?cmd=$EUCLID_QUERY_URL"'
