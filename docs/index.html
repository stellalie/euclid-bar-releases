Why Euclid

Not another extension store or AI subscription. A sharp tool you configure like the rest of your setup.

01 · lightning fast

Native Swift, no web views

No Electron and no JavaScript runtime. Results update on every keystroke, and the footer tells you how long it took.

02 · no AI lock-in

Your agent, your model, your key

AI is just another action. Hand a question to Claude Code, Codex, or a local model through Ollama, in one keystroke. No Euclid AI plan, and none of it is required.

03 · offline by design

Nothing leaves your Mac

Your clipboard, history and index stay on disk. No account, no telemetry, and the licence is checked offline. Every network call, listed.

04 · transparent config

One TOML file, nothing hidden

Every action is one shell line you can read in ~/.config/euclid/config.toml. It reloads on save and --check-config lints it in CI.

05 · extensible

If it runs in a terminal, it's an action

Scripts in ~/.config/euclid/bin are on every action's PATH. Share a team config, import Raycast and Alfred snippets, and let agents search Euclid over MCP.

06 · everything optional

Where your data goes

Euclid works with the network unplugged. These are the only times it goes online.

  • Update checks ask GitHub for the latest version. Turn them off with [updates] check = false.
  • Bitbucket and Jira, only if you set them up, talk straight to your own server, with a token your own command fetches (Keychain, 1Password CLI).
  • Page indexing, off by default, fetches pages you already visited so you can search their text.
  • Your actions do whatever their shell line says, nothing more.
  • Never sent anywhere: what you type, your clipboard, your history, your files, your usage counts.
  • Password managers: copies from 1Password and friends are never recorded.
  • This website counts page views with cookie-free Cloudflare Web Analytics. The app has no analytics at all.

Plugins are just scripts

A folder with a plugin.toml and a script in any language that prints one JSON object per line. No SDK, no build step, no store. Save it and it's in the bar.

# ~/.config/euclid/plugins/tokens/plugin.toml
name = "Claude tokens"

[badge]                     # a chip on the search bar
run   = "./today.sh"        # prints "1.2M tok · $4.10"
refresh_minutes = 5
click = 'ghostty-run tab npx -y ccusage@latest daily'
  • [source] adds items to search, refreshed in the background.
  • [answer] replies to what you type, on a prefix or a regex.
  • [badge] puts a live status on the bar.
  • [[action]] adds commands to ⌘K.
  • Let your AI write one. The format ships as AGENTS.md: ask Claude Code or Codex, check it with --try-plugin.

Ready to add, one command each:

githublinearslacktokenscurrencydefinecontactsshortcuts 
euclid-bar --plugin add github

Recipes, not extensions

Your query arrives as $1, passed as an argument, never pasted into the command.

[[action]]                                   # ⌘1 and ⌘↵
name = "Ask Claude in a new Ghostty tab"
run  = 'ghostty-run tab claude "$1"'

[[action]]                                   # ⌘2
name = "Codex in a herdr split"
run  = 'herdr-run split codex "$1"'

[[action]]                                   # a local model, no API key
name = "Ask Llama on this Mac"
run  = 'ghostty-run tab ollama run llama3.2 "$1"'

[[action]]
name  = "Search GitHub code"
alias = "gh"
run   = 'open "https://github.com/search?type=code&q=$EUCLID_QUERY_URL"'

[[action]]
name = "Pretty-print JSON to clipboard"
run  = 'printf %s "$1" | jq . | pbcopy'
